## Why

长管道目前不能可靠地写成行首管道链，格式化器也会合并已存在的表达式续行。需要支持可读的多行管道，并使超过首选行宽的二元表达式自动断行。

## What Changes

- 允许下一行以 `|>` 或 `<|` 继续当前表达式，无须额外缩进；保持既有优先级和结合性。
- 保留源代码中管道运算符前后的换行，统一续行缩进。
- 超过 100 列的单行二元表达式在运算符后自动换行，覆盖算术、比较、逻辑和管道运算符。
- 保留注释、字面量及内嵌 Go 内容，并保证格式化后的语义及幂等性。
- 其他行首运算符的语句边界规则保持现状。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `parser2-lossless-cst`: 管道跨行的语句边界、无损结构和错误诊断。
- `formatter-cli`: 保留管道换行及超长二元表达式自动断行。

## Impact

影响 parser2 的 CST 语句切分、表达式解析及 formatter 的 Syntax Tree 渲染；实现阶段需同步生成 Go、补充回归测试及语法文档。不增加依赖、不改 AST 运算符模型，也不扩展 legacy parser 的语法。
